# Présentation du Studio
Le dépôt initial contient le service central Django et la route /health/. Aucun template ni composant visuel n’est livré par ARCH-001. La galerie locale utilise Django Templates et des composants Cotton, une feuille Tailwind compilée et du JavaScript natif pour les démonstrations. Le serveur garde la maîtrise de l’activation. Les fondations et composants sont réutilisables sans les données de démonstration. Le CSS livré est local, avec sa source et une commande de compilation reproductible.

Références consultées le 18 novembre 2026 : [installation de Cotton](https://django-cotton.com/docs/quickstart) et [compilation Tailwind](https://tailwindcss.com/docs/installation/tailwind-cli).
