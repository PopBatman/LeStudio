# Point d’entrée Claude

Lire et appliquer [AGENTS.md](AGENTS.md), puis les instructions applicables du dépôt hôte.

Le processus est commun aux runtimes compatibles. Les capacités de délégation, navigation, génération d’images et intégration doivent être constatées dans l’environnement réel. Aucun fichier de ce dossier n’active automatiquement ces capacités ni n’élargit les permissions.

Ne pas inventer de sous-agent, de validation ou de preuve. Les procédures et rôles sont décrits dans le workflow, indépendamment du nom de l’outil utilisé pour les exécuter.
