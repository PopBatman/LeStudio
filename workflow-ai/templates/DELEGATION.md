# Contrat de délégation

<!-- WORKFLOW-AI:TODO -->

| Champ | À renseigner |
|---|---|
| Travail parent | Identifiant et objectif |
| Sous-tâche | Résultat précis |
| Rôle | Responsabilité attribuée |
| Exécution réelle | Identifiant fourni par le runtime, ou indisponibilité constatée |
| Entrées | Documents, contrats et versions |
| Chemins autorisés | Zone d’écriture exclusive ou stratégie de coordination |
| Actions autorisées | Opérations couvertes par le mandat parent |
| Limites | Données, outils, effets externes et exclusions |
| Interfaces | Entrées/sorties partagées avec les autres tâches |
| Critères de fin | Résultat et preuves attendus |
| Retour | Fichiers modifiés, vérifications, limites et questions |

Un sous-agent hérite des limites du parent. Un fichier de rôle ne constitue pas un lancement. Les écritures concurrentes et les modifications hors mandat doivent être signalées immédiatement.
